# 🤖 CLAWDBOT

> Your terminal companion that watches you code and occasionally roasts you

CLAWDBOT is a living character in your terminal that watches you code, makes comments, and keeps you company during those long coding sessions.

## 🚀 Install

```bash
npm install -g clawdbot
```

## 🎮 Usage

```bash
clawdbot
```

CLAWDBOT will start watching you and make comments every few minutes.

## 🎯 Features

- Watches your coding patterns
- Makes funny comments
- Roasts you when deserved
- Keeps you company during late-night sessions
